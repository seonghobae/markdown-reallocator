# Installation

Guide for installing Markdown Reallocator and its dependencies.

## Prerequisites

- Python 3.10+
- Ollama ([download](https://ollama.ai))

## Quick Install

```bash
# Install Ollama models
ollama pull embeddinggemma

# Install package
pip install markdown-reallocator
```

## Verification

```bash
markdown-reallocator --version
```

See detailed installation steps and troubleshooting in the [User Guide](../user-guide/index.md).
